# ⚡ Neon Weather App - Vite & OpenWeather API

Una aplicación web moderna y minimalista para consultar el clima en tiempo real, diseñada con una estética **Cyber-Neon** de alto contraste. Este proyecto fue construido para demostrar el manejo de APIs externas, seguridad de datos mediante variables de entorno y despliegue profesional.

## 🚀 Características

- **Consumo de API:** Uso de la Fetch API de JavaScript para obtener datos meteorológicos de OpenWeatherMap.
- **Diseño Responsive:** Interfaz adaptativa centrada con Bootstrap 5.
- **Estética Neón:** Estilo visual oscuro con efectos de iluminación ciberpunk.
- **Seguridad:** Configuración de variables de entorno (`.env`) para proteger la API Key.
- **Interactividad:** Búsqueda dinámica por ciudad y funcionalidad de cierre de tarjetas individuales.

## 🛠️ Tecnologías Utilizadas

- **Frontend:** HTML5, CSS3, JavaScript (ES6+).
- **Frameworks/Librerías:** Bootstrap 5, Font Awesome.
- **Herramienta de Construcción:** [Vite](https://vitejs.dev/).
- **API:** [OpenWeatherMap API](https://openweathermap.org/api).
- **Despliegue:** Vercel / GitHub Pages.
